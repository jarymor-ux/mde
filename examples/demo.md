# Привет, Markdown

Это **mde** — небольшой редактор Markdown на Rust.

Слева можно редактировать исходный текст, справа — сразу видеть результат.
Переключайте режимы клавишами **⌘/Ctrl 1, 2, 3**.
Команды и темы открываются по **⌘/Ctrl Shift P** или правой кнопкой мыши.

## Обычный текст

Здесь работают **жирный текст**, *курсив*, ~~зачёркивание~~ и `код внутри строки`.

> Хороший инструмент помогает сосредоточиться на тексте.

## Списки

- Открыть несколько файлов одной командой
- Открыть папку и раскрывать её по мере необходимости
- Вернуться к недавним файлам

1. Измените текст слева
2. Посмотрите результат справа
3. Нажмите **⌘S** на macOS или **Ctrl+S** на Windows/Linux
